# pve-creer-lxc

Créer un conteneur LXC non privilégié aux ressources bornées, y mettre un
service en route sous un utilisateur dédié, et prouver que l'isolation et les
limites s'appliquent réellement. Guide : https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/conteneurs-lxc/

```bash
dsoxlab run pve-creer-lxc
dsoxlab check pve-creer-lxc
```
