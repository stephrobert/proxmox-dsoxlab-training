# pve-creer-lxc

Create an unprivileged LXC container with bounded resources, start a service in
it under a dedicated user, and prove that isolation and limits are really
applied. Guide (in French): https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/conteneurs-lxc/

```bash
dsoxlab run pve-creer-lxc
dsoxlab check pve-creer-lxc
```
