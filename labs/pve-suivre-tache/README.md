# pve-suivre-tache

Read the Proxmox task log through the interface and the API, tie each result
to its task, and do not confuse a log with the current state. Guide (in
French): https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/interface-ui/

```bash
dsoxlab run pve-suivre-tache
dsoxlab check pve-suivre-tache
```
