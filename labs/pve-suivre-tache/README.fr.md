# pve-suivre-tache

Lire le journal des tâches de Proxmox par l'interface et par l'API, rattacher
chaque résultat à sa tâche, et ne pas confondre un journal avec l'état
courant. Guide : https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/interface-ui/

```bash
dsoxlab run pve-suivre-tache
dsoxlab check pve-suivre-tache
```
