# verifier-son-installation

Install Proxmox VE 9 yourself on a bare Debian 13, then have the installation
graded item by item against the specification. Guide (in French): https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/installation-debian/

```bash
dsoxlab run verifier-son-installation
dsoxlab check verifier-son-installation
```
