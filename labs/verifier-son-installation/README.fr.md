# verifier-son-installation

Installer soi-même Proxmox VE 9 sur une Debian 13 nue, puis faire noter
l'installation poste par poste face au cahier des charges. Guide : https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/installation-debian/

```bash
dsoxlab run verifier-son-installation
dsoxlab check verifier-son-installation
```
