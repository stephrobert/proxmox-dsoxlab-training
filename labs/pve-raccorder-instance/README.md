# pve-raccorder-instance

Diagnose a VM that cannot be reached from the Proxmox node, plug it into the
right bridge without recreating it, and prove that the fix holds. Guide (in
French): https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/reseau/

```bash
dsoxlab run pve-raccorder-instance
dsoxlab check pve-raccorder-instance
```
