# pve-raccorder-instance

Diagnostiquer une VM injoignable depuis le nœud Proxmox, la rebrancher sur le
bon pont sans la recréer, et prouver que la correction tient. Guide : https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/reseau/

```bash
dsoxlab run pve-raccorder-instance
dsoxlab check pve-raccorder-instance
```
