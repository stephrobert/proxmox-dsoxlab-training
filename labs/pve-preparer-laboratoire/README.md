# pve-preparer-laboratoire

Préparer un environnement jetable, produire son inventaire et démontrer qu’il peut exécuter une VM accélérée.

Read [`scenario.md`](./scenario.md) before starting.

```bash
dsoxlab run pve-preparer-laboratoire
dsoxlab challenge pve-preparer-laboratoire
dsoxlab check pve-preparer-laboratoire
```

Only use resources named in this lab's manifest. Cluster nodes are never provisioned implicitly. Automated success alone does not attest criteria requiring human observation.
