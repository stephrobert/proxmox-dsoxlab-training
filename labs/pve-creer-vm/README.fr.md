# pve-creer-vm

Créer une VM KVM dans Proxmox VE avec le contrat matériel de la leçon, y
installer Debian, et prouver que son service répond depuis l'extérieur de
l'invité, avant et après un redémarrage. Guide : https://www.stephane-robert.info/docs/virtualiser/type1/proxmox/fondamentaux/creer-vm-kvm/

```bash
dsoxlab run pve-creer-vm
dsoxlab check pve-creer-vm
```
