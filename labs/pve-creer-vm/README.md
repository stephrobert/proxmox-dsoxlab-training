# pve-creer-vm

Create a KVM VM in Proxmox VE with the lesson's hardware contract, install
Debian on it, and prove that its service answers from outside the guest,
before and after a reboot. Guide: https://www.stephane-robert.info/en/docs/proxmox/create-kvm-vm/

```bash
dsoxlab run pve-creer-vm
dsoxlab check pve-creer-vm
```
